# NOTICE

FluxTie Desktop is a Windows port of FluxTie, an unofficial Tieba client for Android.

- Upstream project: https://github.com/makise2060/FluxTie (GPL-3.0)
- Original work: HuanCheng65/TiebaLite — https://github.com/HuanCheng65/TiebaLite
- Protocol reference: aiotieba, tbclient.protobuf

The desktop implementation (WPF / .NET) is original code written for this port. It reuses
the upstream project's `.proto` definitions and emoticon image assets, and talks to the
official Baidu Tieba endpoints directly, the same way the Android client does.
